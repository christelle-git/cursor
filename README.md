# ReVidéo Studio

Outil de génération vidéo IA « video-to-video » : partez d'une vidéo existante et transformez-la par IA (restylisation ou édition guidée par prompt), en préservant le mouvement d'origine.

L'application se trouve dans [`revideo-studio/`](revideo-studio/) — voir son [README](revideo-studio/README.md) pour l'installation et la documentation.

```bash
cd revideo-studio
npm install
cp .env.example .env.local   # renseignez votre clé FAL_KEY (https://fal.ai/dashboard/keys)
npm run dev
```
